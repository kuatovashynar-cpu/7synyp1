Қысқаша көбейту формулалары

7-сынып · Алгебра. Көпмүшені көбейтпей-ақ, дайын формуламен жылдам есептеуді үйренеміз.

Неге (a + b)² = a² + 2ab + b²?

Қабырғасы a + b шаршыны төрт бөлікке бөлеміз. Жүгірткілерді жылжытыңыз:

Теория

Қосындының квадраты

(a + b)² = a² + 2ab + b²

Бірінші санның квадраты, қосу екі еселенген көбейтінді, қосу екінші санның квадраты.

Айырманың квадраты

(a − b)² = a² − 2ab + b²

Ортасындағы екі еселенген көбейтіндінің таңбасы теріс.

Квадраттар айырмасы

a² − b² = (a − b)(a + b)

Екі квадраттың айырмасы — айырма мен қосындының көбейтіндісі.

Кубтардың қосындысы

a³ + b³ = (a + b)(a² − ab + b²)

Кубтардың айырмасы

a³ − b³ = (a − b)(a² + ab + b²)

Жиі қате

(a + b)² ≠ a² + b². Тексеріңіз: a = 2, b = 3 болса, (2 + 3)² = 25, ал 2² + 3² = 13. Ортаңғы 2ab = 12 жоғалып кетті.

Мысалдар

Алдымен өзіңіз шешіп көріңіз, содан кейін жауабын ашыңыз.

1. (3x + 2)² өрнегін жазыңыз

Мұнда a = 3x, b = 2.

(3x)² + 2·3x·2 + 2² = 9x² + 12x + 4

2. 64 − 25y² өрнегін көбейткіштерге жіктеңіз

64 = 8², 25y² = (5y)².

8² − (5y)² = (8 − 5y)(8 + 5y)

3. 97 · 103 көбейтіндісін санаңыз (калькуляторсыз)

97 = 100 − 3, 103 = 100 + 3.

(100 − 3)(100 + 3) = 100² − 3² = 10000 − 9 = 9991

4. 49² санын жылдам есептеңіз

49 = 50 − 1.

(50 − 1)² = 2500 − 100 + 1 = 2401
